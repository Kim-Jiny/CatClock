· 이 폴더(Sources/CatClock/Cats/)에 PNG(권장, 투명 배경)·JPG 등 이미지 파일을 그냥 떨어뜨리면
  앱의 "고양이 종류" 목록에 자동으로 추가됩니다.
· 파일 이름(확장자 제외)이 그대로 고양이 이름이 됩니다.
    예) "고등어냥.png"  →  목록에 "고등어냥" 으로 표시
· 투명 배경 PNG 를 쓰면 위젯에 박스 없이 모양대로 떠요.
· 이미지를 추가/변경한 뒤에는 다시 빌드하세요:
    개발 실행:  swift run
    배포 빌드:  ./build_app.sh   (또는 ./build_app_mas.sh)
